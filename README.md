# Экономическая свобода бизнеса и автономия муниципалитетов

Статический исследовательский сайт по работе Михаила Александровича Сапогова. Содержит адаптивные схемы, справочные окна к источникам и интерактивный калькулятор трёх моделей налогового стимулирования.

## Локальный запуск

Сайт не требует сборки или установки зависимостей. Откройте `index.html` напрямую (тогда часть функционала будет недоступна) либо запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Все пути в проекте относительные, поэтому сайт работает как на пользовательском домене, так и по адресу `https://<имя>.github.io/<репозиторий>/`.

## Структура

- `index.html` — содержание и семантическая разметка;
- `styles.css` — оформление, адаптивность и печатная версия;
- `src/main.js` — источники, подсказки, калькулятор и навигация;
- `assets/fonts/` — локальные файлы шрифта и лицензия.

Данные калькулятора не отправляются на сервер и нигде не сохраняются.
